## Черновик текста

### book-main - раздел 4.5

```text
Device API - это прикладной слой описания устройств Bus77. Он не заменяет сам протокол обмена, а задает модель того, какие типы устройств существуют, какие у них Device ID, какие каналы управления и обратной связи доступны и какими функциями эти каналы описаны.

В Device API канал управления (КУ) - это канал, в который система или инструмент может записать команду или значение. Канал обратной связи (КОС) - это канал, из которого система получает состояние, событие или измерение устройства. Для каждого канала фиксируются FID, тип значения, флаги доступа, обязательность, единицы измерения и версия API.

При проверке Device API нельзя считать FID уникальным сам по себе. Один и тот же FID может встречаться в разных направлениях или классах каналов. Для сверки используется ключ: Device ID + направление/класс канала + FID + функция.

Полные таблицы Device API, SDK и reference implementations являются внутренними источниками проекта Bus77 Protocol Knowledge. В стандарт переносится только согласованное объяснение и правила применения.
```
