Эта папка является source-owned workspace внутри проекта `001_77_Standard_iRidi`.

## Правило

- Не выносить эту папку обратно в корень CORD без отдельного решения.
- Канонический проектный контекст хранится в [[01_Projects/001_77_Standard_iRidi/Standard_iRidi_MOC]].
- Предложения по изменениям стандарта сначала идут в project review/proposal.
- Публикация в Google Doc, Wiki или стандарт выполняется только после approve.

## Зачем она отдельным workspace

Это рабочая копия/источник стандарта с собственной структурой, versioning and source artifacts. CORD хранит ее внутри проекта как вложенный workspace, чтобы не смешивать legacy workflow `inbox/archive/sources` со standard CORD scaffold.
