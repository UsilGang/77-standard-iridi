# inbox — очередь на обработку агентом

Сюда попадает **уже обработанная** информация (не сырьё): выжимка из встречи, экспертного совета, поля, тикета или релиза — готовая к тому, чтобы агент предложил правки в книгу стандарта и/или Wiki.

## Кто кладёт

- Вы или коллега после ручной/ИИ-обработки источника
- Агент при «осадке» сессии — **только** если материал структурирован по шаблону
- Автоматические пайплайны (транскрипт → summary) — в подпапку с пометкой `source` в `meta.yaml`

## Формат

Одна задача = одна папка:

```
inbox/
  YYYY-MM-DD_краткий-slug/
    meta.yaml      # метаданные и маршрутизация
    content.md     # обработанный материал (факты, формулировки)
    proposal.md    # заполняет агент: предлагаемые изменения
```

Шаблон: [[01_Projects/001_77_Standard_iRidi/Workspace/77_Стандарт_iRidi/inbox/_template/README]].

## Статусы в inbox


| status        | Значение                               |
| ------------- | -------------------------------------- |
| `pending`     | Ждёт взятия агентом в работу           |
| `in_progress` | Агент готовит `proposal.md`            |
| `review`      | Предложение отдано вам на согласование |


## Что делает агент

1. Берёт папки со `status: pending` (или по вашей команде).
2. Читает `content.md`, сверяет с разделами книги (см. `AGENTS.md` → маршрутизация).
3. Пишет `proposal.md`: куда в книге/Wiki, черновик текста, обоснование, риски.
4. Ставит `status: review` в `meta.yaml`.
5. **Не правит** Google Doc / Wiki до вашего решения.

## После согласования с вами


| Решение       | Действие                                                                              |
| ------------- | ------------------------------------------------------------------------------------- |
| **Применено** | Правки внесены в книгу/Wiki → папка в `archive/` со `resolution: applied`             |
| **Отклонено** | Папка в `archive/` со `resolution: rejected` и комментарием почему                    |
| **Частично**  | Применённое зафиксировано → `resolution: partial`, остаток можно новой папкой в inbox |


Перенос в archive делает агент **только после явного вашего «ок» / «отклонить»**.
